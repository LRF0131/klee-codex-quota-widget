# Security policy

## Supported version

Only the latest published release is actively supported.

## Reporting a vulnerability

Please do not publish tokens, account IDs, session content, or security reports
in a public issue. Use GitHub's private vulnerability report form:

https://github.com/LRF0131/klee-codex-quota-widget/security/advisories/new

Include the affected version, expected behavior, reproduction steps, and any
relevant logs after removing personal information and credentials.
