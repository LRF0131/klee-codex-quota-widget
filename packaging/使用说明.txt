Klee Codex 额度任务栏组件 1.5.0
================================

适用系统
--------
Windows 11（64 位）。无需管理员权限。

安装前
------
1. 在这台电脑上安装并打开 Codex。
2. 登录你要监控额度的 ChatGPT 账号。
3. 确认 Codex 中能正常看到 Usage/额度信息。

安装
----
1. 先把 ZIP 完整解压，不要直接在压缩包内运行。
2. 双击 Install.cmd。
3. 安装后组件会立即启动，并在以后登录 Windows 时自动启动。
4. 安装程序会在桌面创建“Codex Quota Widget”快捷方式。

安装位置
--------
%LOCALAPPDATA%\KleeCodexQuotaWidget\KleeCodexQuotaWidget.exe

使用
----
- 程序运行时会在任务栏通知区域常驻图标；隐藏时请展开“显示隐藏的图标”。
- 托盘图标悬停显示额度和任务状态，双击刷新，右键打开完整菜单。
- 组件意外退出或找不到时，双击桌面的 Codex Quota Widget 快捷方式重新启动。
- 修复 175% DPI 下菜单裁切；菜单按所在显示器 DPI、文本大小重新测量，空间不足时换行。
- 右键 Logo，直接拖动菜单内缩放滑杆实时调节 50%–200%，收起后保存；可恢复默认。
- 缩放跟随系统 DPI，过大时自动限制在任务栏范围内，点击区域同步缩放。
- 拖动 Logo：微调显示位置；双击 Logo：刷新额度。
- 右键 Logo：刷新、切换显示器及其他设置。文字区域鼠标穿透。
- Codex 执行任务时 Logo 旋转；完成后显示绿色小勾。
- 只有 Tibo 明确宣布未来重置时间时，才显示倒计时。
- 检测到额度恢复时只标记“额度已恢复”，不推断是谁触发。
- 7d 归零且账户有可用重置时，显示“可重置 ×N”，否则显示已知恢复日期。
- 5h 低于 10% 时显示恢复时间；7d 未归零时不提示重置次数。
- 右侧优先级：额度已恢复、7d 归零、Tibo 预告、5h 低额度。
- 背景逐像素透明，Logo 点击区域为极低透明度，便于拖动和右键。
- 重置次数减少并且额度明显恢复后，绿色显示“额度已恢复”五分钟。
- 组件不会自动使用你的重置机会。

更新
----
收到新版后完整解压，再双击新版 Install.cmd，会覆盖程序并保留设置。

卸载
----
双击 Uninstall.cmd。它会关闭组件并取消开机启动。
额度缓存和日志会保留在安装目录，可自行删除。

隐私与账号
----------
- 安装包不包含制作者电脑的登录令牌、额度缓存、设置或日志。
- 程序只读取本机 Codex 的登录状态和使用额度。
- 请勿复制别人的 .codex/auth.json；在新电脑上正常登录即可。

安全提示
--------
这是个人自用构建，未购买代码签名证书，因此 Windows 可能显示
“未知发布者”或 SmartScreen 提示。请先对照 SHA256.txt 校验文件。
不要关闭 Defender，也不要对来源不明或哈希不一致的文件点“允许”。

故障排查
--------
- 一直显示 --：先打开 Codex 并确认已登录，然后右键组件手动刷新。
- 额度不更新：检查这台电脑的网络或代理是否也能让 Codex 正常联网。
- 看不到组件：在任务管理器结束 KleeCodexQuotaWidget，再重新运行。
